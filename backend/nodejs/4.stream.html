# isBuffer方法

isBuffer方法用于判断一个对象是否为一个Buffer对象。

> a = 'aaa';
'aaa'
> b = new Buffer(10);
<Buffer f0 e6 bf 5f ff 7f 00 00 00 00>
> typeof(a);
'string'
> typeof(b);
'object'
> Buffer.isBuffer(a);
false
> Buffer.isBuffer(b);
true
